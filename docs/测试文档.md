## 1. 测试环境

| 项 | 值 |
|---|---|
| 操作系统 | Windows 10 x64 |
| Flutter | 3.32.5（Dart 3.8.1） |
| 测试框架 | flutter_test + flutter_lints 6 |
| 数据库测试 | sqflite_common_ffi 2.3.6（`databaseFactoryFfiNoIsolate`，无需真机/模拟器） |

运行方式：

```bash
flutter pub get     # 安装依赖（含 dev 依赖 sqflite_common_ffi）
flutter analyze     # 静态分析，期望：No issues found!
flutter test        # 运行全部测试
```

单个文件运行示例：

```bash
flutter test test/lottery_test.dart
flutter test test/widget_test.dart --plain-name "盲盒页勾选分类后可以抽签并确认"
```

```

flutter test     →  00:12 +43: All tests passed!（43 个用例；首轮迭代前仅 1 个测试且为失败状态）
```

第二轮自检修复后新增 5 个用例：copyWith 哨兵模式、上桌次数完整计数、同一天 午餐→晚餐 排序、分类排序号不重复、图片清理容错。测试耗时约 12 秒，全部在宿主机完成，无需连接设备。

## 4. 测试基建说明（写给后续维护者）

1. **数据库注入**：`test/helpers/test_db.dart` 的 `initTestDatabaseFactory()` 必须在 `setUpAll` 中 await——sqlite3 动态库加载涉及真实异步 I/O，若推迟到 `testWidgets` 的 FakeAsync 区内触发会永远无法完成。
2. **FakeAsync 与真实 I/O**：`sqflite_common_ffi` 的部分内部实现依赖真实事件循环。Widget 测试统一使用 `runAsync` 模式（见 `pumpApp`/`pumpAfterInteraction`）：先用 `runAsync` 打开真实异步窗口完成数据库工作，再 `pumpAndSettle` 收敛 UI 帧。
3. **视口遮挡**：盲盒页内容较长，底部控件在默认 800×600 视口下会被底部导航遮挡导致 `tap()` 落点偏移，抽签用例通过 `setSurfaceSize` 放大视口解决。
4. **隔离**：每个用例独立的临时数据库目录与图片根目录（`ImageService.debugSetRoot`），用例间零共享。
